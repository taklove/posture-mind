## 1. 执行摘要

### 一句话定位
**正形 PostureMind** 是一款基于 AI 姿态识别 + 运动康复知识库的体态矫正 APP。它不只是告诉你"哪里不对"，而是告诉你"哪块肌肉该发力却没发力"，并给你每天 10 分钟的针对性训练。

### 核心数字（24 个月目标）
- **TAM**（可寻址市场）：中国体态矫正/运动康复市场 ≈ 800 亿

- **次年目标**：300 万下载，30 万付费用户

### 融资计划
- **种子轮**：300-500 万人民币

- **退出路径**：3 年内被运动健康平台/智能硬件公司并购，或独立 D 轮上市

## 2. 痛点与机会

### 2.1 一个被忽视的"国民问题"

**数据**：
- 中国 18-45 岁人群中，**86%** 存在不同程度的体态问题（圆肩、骨盆前倾、头前伸等）
- 其中只有 **3%** 寻求过专业指导（运动康复师 / 物理治疗师）
- 体态问题引发的次生健康问题：颈椎病（患者 2 亿+）、腰椎间盘突出（患者 4000 万+）、慢性肩颈痛

**为什么没人管**：
1. **不知道怎么管**：体态问题不像"减肥"，没有明确的"秤上的数字"
2. **找不到人**：一个合格的运动康复师在一线城市 ¥400-800/h，县级城市基本没有
3. **传统方案反人性**：让你去健身房举铁 1 小时，90% 的人坚持不了 2 周
4. **认知错误**：99% 的人认为"我身体硬，所以要去拉伸"——但实际上"硬"是结果，不是原因

### 2.2 现有方案的致命缺陷

| 现有方案 | 致命问题 |
|---|---|
| 健身 APP（Keep 等） | 通用训练计划，不针对你的体态偏差；你骨盆前倾还在练深蹲，会越来越糟 |
| 体态检测硬件（智能镜子） | 5000+ 元，价格不亲民；只能看，不能给训练 |
| 按摩/拉伸课程 | **方向反了**——你拉的是代偿肌，不是根源，治标不治本 |
| 运动康复诊所 | 单次 ¥400+，无法日常化 |

### 2.3 我们的洞察

> **体态问题不是"哪块肌肉太紧"，而是"哪块肌肉该发力却没在发力"。**

这是一个反直觉的认知，但它是运动康复领域的共识。我们的产品把这个"专业认知"变成了"普通用户能理解的诊断 + 训练"。

## 3. 我们的解法

### 3.1 核心方法论

**3 步：识别 → 归因 → 激活**

1. **识别**：拍 3 张照片（正/侧/背），AI 提取 33 个关键点
2. **归因**：诊断出"你有哪些代偿肌 + 哪些该发力的肌肉在偷懒"
3. **激活**：每天 10 分钟，4-6 个针对性训练动作

### 3.2 产品哲学（差异化核心）

**对每种体态问题，我们都给两栏信息**：
- 🔴 **代偿肌**（看起来紧的 — 不是问题根源）
- 🟢 **该发力却没发力的**（这才是根源）

这跟市面上所有竞品都不一样。我们的内容不是"健身教程合集"，而是**结构化的诊断 → 治疗知识图谱**。

### 3.3 产品形态

- **PWA 验证版**（已上线）：https://krfm2m3gl6wk2.space.mcode.cn
- **iOS 原生**（规划中）
- **Android 原生**（已启动开发）

## 4. 产品详解

### 4.1 核心功能（已实现）
- ✅ 拍照/上传体态照片
- ✅ AI 关键点检测（MediaPipe Pose，33 个点）
- ✅ 8 种常见体态问题自动诊断
- ✅ 代偿肌 vs 应发力肌对照展示
- ✅ 针对性训练计划生成
- ✅ 14 个训练动作（含动作示范、要点、避错）
- ✅ 训练计时器 + 完成记录
- ✅ 历史记录 + 进度跟踪

### 4.2 规划功能
- 📅 **视频评估**（v2.0）：用短视频替代照片，分析动态姿势
- 📅 **运动检测**（v2.0）：摄像头实时检测训练动作是否标准
- 📅 **AI 教练**（v3.0）：根据你的进度，GPT 自动调整训练计划
- 📅 **教练端**（v3.0）：B 端，运动康复师管理多个用户
- 📅 **Apple Watch / Wear OS**（v3.0）：训练实时监测心率、动作质量

### 4.3 技术栈

| 模块 | 方案 | 理由 |
|---|---|---|
| 姿态检测 | **MediaPipe Tasks** | Google 官方，30+ FPS，移动端友好 |
| 前端（PWA） | 原生 HTML/CSS/JS | 0 依赖、加载快、好维护 |
| iOS | **Swift + SwiftUI + MediaPipe iOS SDK** | 原生性能、App Store 生态 |
| Android | **Kotlin + Jetpack Compose + MediaPipe Android SDK** | 现代声明式 UI |
| 后端（后期） | **Node.js / Python** | 灵活，开发快 |
| 数据库 | **PostgreSQL**（用户数据）+ **Redis**（缓存） | 稳定可靠 |
| ML 模型 | 前期用 MediaPipe 自带，**后期自训**（基于真实用户数据） | 飞轮效应 |

## 6. 商业模式

### 6.1 订阅 + 内容 + 服务的三层模型

**Layer 1：免费层（引流）**
- 3 张照片评估
- 2 个训练动作 / 天
- 基础的"代偿肌 vs 应发力肌"诊断
- 目的：让用户看到自己的问题，建立信任

**Layer 2：订阅层（主力收入）**
- ¥29/月 / ¥199/年
- 完整训练计划
- 视频评估
- 进度对比（前后对比图）
- 推送提醒
- 新内容每周更新

**Layer 3：服务层（高客单）**
- 1V1 远程教练咨询（¥199-499/次）
- 专项训练包（"30 天改善骨盆前倾" ¥99）
- 礼品订阅（送朋友/家人）

## 7. 竞争分析

### 7.1 竞争格局

| 竞品 | 优势 | 我们的差异化 |
|---|---|---|
| **Keep** | 品牌大、用户多 | 它们做"通用训练"，我们做"针对性矫正" |
| **薄荷健康** | 健康管理 | 它们关注"体重/饮食"，我们关注"体态" |
| **Home Fitness** | 视频多 | 视频 ≠ 精准 |
| **运动康复诊所（线下）** | 专业 | 贵 + 不可及 + 不可日常化 |
| **智能镜子（添可等）** | 硬件体验 | 5000+ 元，只检测不训练 |

### 7.2 护城河

1. **内容壁垒**：8 种体态问题 × 多个代偿/应发力肌组合，这是**专业结构化知识图谱**，不是 UGC 内容
2. **数据壁垒**：用户训练数据越多，AI 越精准（飞轮）
3. **品牌壁垒**："正形" = "体态矫正代名词"（长期目标）

### 7.3 潜在威胁
- 抖音/小红书 KOL 做体态训练（轻量、不专业）
- 大厂进入（华为/小米健康、苹果 Health）

**对策**：保持内容专业深度 + 提前建立数据飞轮
